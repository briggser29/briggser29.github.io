How to export your Audible library
  1. One time: in Terminal (Mac) or Command Prompt (Windows), not inside Python, install audible-cli. On a Mac use python3 in place of py.
    py -m pip install audible-cli
  2. One time: sign in to Audible.
    audible quickstart
  3. Each time you want to sync: export your library.
    audible library export -f json -o audible-library.json
  4. Click Import from Audible and pick audible-library.json. You'll see every change before anything is saved.
